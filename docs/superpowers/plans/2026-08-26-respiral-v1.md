# Respiral V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a private, offline native Android app that lets its owner save, revisit, and safely export Markdown-based personal affirmations, achievements, and “Who I Am” notes.

**Architecture:** A Kotlin/Jetpack Compose app owns the presentation and navigation. A repository writes canonical Markdown and private media atomically into app-private storage, while Room maintains a rebuildable local index and DataStore stores non-vault settings. Android system integrations provide biometrics/passcode authentication, local notifications, home-screen widgets, camera/gallery import, and file-picker ZIP export/import.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Navigation Compose, Room, DataStore, AndroidX Biometric, Glance AppWidget, AlarmManager, Storage Access Framework, JUnit, Truth, Compose UI testing, AndroidX Test.

**Spec:** `docs/superpowers/specs/2026-08-26-respiral-design.md`

## Global Constraints

- Support Android 10 (API 29) and newer; set `minSdk = 29`.
- Use native Kotlin and Jetpack Compose; do not add a network permission, account system, analytics SDK, cloud service, or automatic sync.
- Keep every vault entry as canonical Markdown and every photo in app-private storage; Room is a rebuildable index only.
- Copy gallery/camera photos into the vault; never retain a gallery URI as the only attachment reference.
- Notifications are opt-in and off by default. Widgets do not display vault text by default.
- The app lock is opt-in. When enabled it accepts native biometrics with device-passcode fallback, expires after five minutes of inactivity, and locks immediately on phone lock.
- Use the exact user-facing primary copy: “Remind me who I am” and “Add something good”.
- Use the agreed palette: paper `#ead9b8`, espresso `#2b1d16`, sage `#93a486`, muted terracotta `#bb7357`, mustard `#d9a92e`.
- Avoid streaks, scoring, feeds, mood judgement, generative advice, and voice-note capture.
